# Third-Party Media

## Free Exercise DB

- Source: https://github.com/yuhonas/free-exercise-db
- License: The Unlicense / public domain
- Use in SOMETHING: two exercise demonstration frames are displayed in an
  alternating two-frame animation.
- Bundled exercises: 27 bodyweight and mobility movements that can be mapped
  accurately to the source dataset.

The popular `hasaneyldrm/exercises-dataset` GIF collection is not bundled.
Its repository license explicitly excludes the `images/` and `videos/` media;
that media is owned by Gym Visual and requires a separate license.

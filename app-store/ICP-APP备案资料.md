更新日期：2026-11-14  
用途：复制到阿里云、腾讯云、华为云、火山引擎等备案软件。  
注意：Apple 后台字段写作“ICP 备案号”，移动应用应向备案服务商申请 **App 备案号**，不要填网站备案号。

## 1. 必填主体信息

| 项目 | 填写值 |
|---|---|
| 备案主体类型 | □ 个人　□ 企业/单位 |
| 主体名称 | `与身份证或营业执照完全一致` |
| 证件号码 | `本人填写，勿发给代办以外的人` |
| 证件有效期 | `本人填写` |
| 主体所在地 | `省 / 市 / 区县，须与证件或实际经营地一致` |
| 负责人姓名 | `本人填写` |
| 手机号 | `本人填写` |
| 邮箱 | `本人填写` |
| 通信地址 | `本人填写` |

如果以个人身份备案，主体名称和负责人必须是同一自然人。不能直接把 App Store 团队名、版权名或品牌名当作法定主体名称。

## 6. 容易填错的字段

- App 名称：`Somethings`
- Bundle ID：`com.acanxp.trellis`
- 不要填 GitHub 仓库地址作为 App 域名。
- 不要把 `github.io` 写成 App 的服务器域名。
- 不要声明“收集健康数据”；当前产品事实是本机处理且不上传。
- 如果备案服务商要求选择“服务类型”，选效率/工具类，不要选医疗服务或诊疗。
- 最终提交前，主导者姓名、证件信息必须与 Apple Developer 账号实名主体可解释一致。

## 7. 当前无法由代码自动生成的内容

以下内容只能由备案主体本人或代办人员依法填写：

- 身份证号、证件有效期、住址、手机号、邮箱。
- 人脸识别、短信核验、真实性核验签字。
- 备案服务商分配的接入商信息和最终 App 备案号。

备案号获批后，再填入 App Store Connect 的“中国大陆 ICP 备案号”；首版其他地区上架不依赖该号码。
